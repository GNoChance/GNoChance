## 🎯 Projets

### 🎮 MCNetwork — Plateforme Minecraft Full-Stack
**React · TypeScript · Vite · Java · Spring Boot**

Site web complet pour un serveur Minecraft avec une architecture full-stack moderne :

- **Frontend** : Application React/TypeScript avec Vite, rendu de skins via l'API Mojang, dashboard joueur, historique et système d'authentification
- **Backend** : API REST en Java/Spring Boot gérant la logique serveur
- Interface responsive et expérience utilisateur soignée

> *Ce projet m'a permis de concrétiser mon objectif d'apprendre React — et de pousser jusqu'au full-stack avec Spring Boot.*
